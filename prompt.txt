So I want to build my own browser. Of course I do not want to build everything from scratch. We can use open source stuff etc. The reason I want to do this is because I am sick of adverts and all the tracking that existing browsers do. So my browser does not have to be fancy, and have all the bells and whistles. As long as it can display a web page, have tabs and bookmarks I am happy. It does not even need to read my cookies from chrome. It can have its own cookie db. In fact I would like that, I would like to see what cookies it is storing and be able to delete them. Let me know if this is possible and how we would go about doing it. This is a non-trivial project. So lets plan it out thorougly and write out the plan before we start even a line of code. Ask any questions.

  Also this is a mac. As long as it runs on a mac (apple silicon) I am ok. It does not even have to be cross platform for now.

Performance is critical. I do not want a slow browser. Fast startup, responsive tabs and navigation, smooth page rendering, and reasonable memory and CPU usage should be treated as first-class requirements. We should prefer a simple, native-feeling architecture and avoid unnecessary layers or features that would make the browser sluggish. The plan should include measurable performance targets and a way to benchmark them throughout development.
